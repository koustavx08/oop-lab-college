# OOP Lab College

A collection of Java programs and practical assignments for learning Object-Oriented Programming (OOP) concepts.

## About

This repository contains college OOP lab programs written in Java. The programs focus on fundamental programming concepts, classes, objects, methods, conditional statements, loops, and basic problem-solving.

## Programs

### Day 1

| Program | Description |
| --- | --- |
| `day1/HelloWorld.java` | Prints a `Hello World` message. |

- **Language:** Java
- **Paradigm:** Object-Oriented Programming
- **Recommended JDK:** Java 8 or later

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/koustavx08/oop-lab-college.git
cd oop-lab-college
```

### 2. Compile a program

For example:

```bash
javac day1/HelloWorld.java
```

### 3. Run the program

```bash
java -cp day1 HelloWorld
```
